## Conexión

- **¿Cómo se aplica la IA en el desarrollo de software?**
  - Desde auto-completar hasta orquestación de agentes.
- **¿Qué tipo de herramientas se utilizan?**
  - Extensiones de editores.
  - Agentes de linea de comandos.
  - Plataformas en la nube.
- **¿Cuáles son los escenarios más comunes?**
  - Creación de proyectos nuevos, _greenfield_.
  - Mantenimiento, refactorización de proyectos existentes, _brownfield_.

---

## Conceptos

### Nivel de automatización

- 0. Código manual
- 1. Auto-completado
- 2. Vibe-coding
- 3. Spec-driven development
- 4. Orquestación de agentes

--- 

### Herramientas que usan GitHub Copilot

- **Editores**: VSCode, Visual Studio 202*, IntelliJ, Neovim
- **CLI**: GitHub Copilot CLI, OpenCode CLI
- **Plataformas**: GitHub Codespaces

---

### Escenarios comunes

- **Greenfield**: Crear un proyecto nuevo desde cero.
  - `Create a new ASP.NET Core Web API project targeting .NET 10 with the name OrderService`
- **Brownfield**: Mantener o refactorizar un proyecto existente.
  - `/doc` `/explain` `/fix` `/refactor` `/test` `/generate`
